## Agent skills

### Issue tracker

Issues live as GitHub issues; use the `gh` CLI for all operations. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles map to the default label names (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` at the repo root plus `docs/adr/`. See `docs/agents/domain.md`.
